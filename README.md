# Twiglles Sales — воронка продаж Твиглс

Статический сайт-дашборд отдела продаж: воронка от исходящих контактов до оплат, разбивка по месяцам и менеджерам, касса по дням, раздел «Наблюдения» и сверка данных. Страница открывается по паролю, данные таблицы лежат в репозитории только в зашифрованном виде.

Сервера нет: Node.js нужен для сборки и тестов, а на сайте работает обычный HTML, CSS и JavaScript.

## Быстрый старт

```bash
npm test        # проверка расчётов, шифрования и сборки
npm start       # сборка и просмотр на http://localhost:8080
npm run build   # только сборка в dist/
```

Нужен Node.js 20 или новее. Зависимостей нет, `npm install` не требуется.

## Калькулятор ЗП (/zp/)

Страница `/zp/` открывается по паролю. В репозитории лежат только страница входа `zp/index.html` и зашифрованное приложение `zp/app.enc.json` (тот же PBKDF2 + AES-GCM, что и у данных дашборда). Открытый исходник в репозиторий не кладут. Чтобы обновить приложение: `PIN=пароль node scripts/encrypt-zp.js путь/к/index.html`, затем закоммитить `zp/app.enc.json`. Цифры менеджеров хранятся в Google-таблице через Apps Script, не в репозитории.

## Как устроено

```
src/
  index.html      каркас страницы и форма пароля
  styles.css      оформление
  core.js         расчёты: разбор выгрузки таблицы, свод, конверсии, проверки данных
  app.js          интерфейс: вход по паролю, вкладки месяцев, блоки, «Наблюдения»
data/
  snapshot.enc.json   зашифрованная выгрузка таблицы (PBKDF2-SHA256 + AES-256-GCM)
scripts/
  build.js        собирает сайт в dist/
  encrypt-data.js шифрует новую выгрузку
  serve.js        локальный просмотр
test/             тесты на node:test
.github/workflows/deploy.yml   публикация на GitHub Pages
```

Расшифровка идёт в браузере, после ввода пароля. Опция «запомнить на этом устройстве» хранит пароль в localStorage браузера.

## Автообновление данных

Workflow `.github/workflows/refresh-data.yml` каждые 30 минут (и по кнопке «Run workflow») забирает таблицу, шифрует её и, если цифры изменились, коммитит `data/snapshot.enc.json` и запускает публикацию сайта. Таблица остаётся закрытой: данные отдаёт маленький скрипт Google Apps Script (`apps-script/Code.gs`), который отвечает только на запрос с секретным словом.

Что настроить один раз:

1. В таблице: «Расширения → Apps Script», вставить код из `apps-script/Code.gs`, заменить `SECRET` своим секретным словом, затем «Развернуть → Новое развёртывание → Веб-приложение», доступ «Все». Скопировать адрес развёртывания.
2. В GitHub: Settings → Secrets and variables → Actions → New repository secret, добавить три секрета: `SHEET_URL` (адрес из шага 1), `SHEET_KEY` (секретное слово) и `PIN` (пароль страницы).
3. Вкладка Actions → «Refresh dashboard data» → Run workflow: проверить, что запуск зелёный.

Если секреты не заданы, workflow просто падает с понятным сообщением, а сайт остаётся с прежними данными. Ручной способ из раздела ниже по-прежнему работает.

## Как обновить данные вручную

1. Скопируйте текст выгрузки таблицы в файл `snapshot.txt` (он в `.gitignore` и в репозиторий не попадёт). Формат: листы с заголовками `# Сентябрь`, `# Октябрь` и блоки «Отдел продаж», «Кристина», «Соня», «Маша», «Настя» со строками показателей через запятую.
2. Зашифруйте: `PIN=ваш_пароль npm run data -- snapshot.txt`. Скрипт проверит разбор и расшифровку и напечатает итоги (касса, КП, счета, оплаты).
3. Закоммитьте `data/snapshot.enc.json` и отправьте в `main`. Сайт пересоберётся и опубликуется сам.

Пароль в репозитории нигде не хранится. Чтобы сменить пароль, зашифруйте данные заново с новым `PIN`.

## Публикация на GitHub Pages

1. В репозитории откройте Settings → Pages и выберите источник **GitHub Actions**.
2. Отправьте код в ветку `main`. Workflow `deploy.yml` прогонит тесты, соберёт `dist/` и опубликует сайт.

Ссылки на файлы в сайте относительные, поэтому он работает и по адресу вида `https://аккаунт.github.io/репозиторий/`, и на своём домене.

## Безопасность

- Данные зашифрованы, но пароль из четырёх цифр можно подобрать перебором, если кто-то скачает `data.js`. Для надёжной защиты используйте длинный пароль (от 10 символов).
- Открытую выгрузку (`snapshot.txt`) и пароль не коммитьте. Файл `.gitignore` уже исключает `snapshot.txt` и `.env`.
- В `<meta name="robots">` стоит `noindex`, поисковики страницу не индексируют.

## Что считает страница

- «Деньги в кассе» берутся как сумма дневных ячеек строки «Деньги в кассе». Итоговая ячейка отдела в таблице бывает устаревшей, страница показывает расхождение в блоке «Проверка данных».
- Показатели менеджера (КП, счета, оплаты) равны сумме дневных ячеек. Ячейка «Факт» определяется как та, что равна сумме дней, поэтому план, случайно совпавший с суммой, не принимается за факт (это закрыто тестом).
- Месяц «идёт» считается по текущей дате: для него показываются темп и прогноз.
